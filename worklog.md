# Mimie's Study — Worklog

Project: Mimie's Study — Midwifery Learning Academy (single-page Next.js app on `/`)
Stack: Next.js 16 App Router + TypeScript + Tailwind 4 + shadcn/ui + Prisma (SQLite) + framer-motion + recharts + zustand

Constraints (sandbox):
- Only `/` route is user-visible → the whole app is a client-side SPA with view-based routing (dashboard / curriculum / lesson / quiz / games / progress / profile / admin), backed by API routes under `/api/*`.
- Prisma + SQLite replaces Supabase. Cookie-based session auth replaces NextAuth for simplicity.
- Brand palette: blush pink, dusty rose, lavender, cream, plum, burgundy, sage — NO blue/indigo.
